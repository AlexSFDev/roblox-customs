# Userscripts

A collection of custom userscripts for modifying and enhancing websites through [Tampermonkey](https://www.tampermonkey.net/).

## Scripts

| Script                    | Description                                                                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Custom Friends**        | Adds customizable Roblox users to the Friends carousel, including avatars, presence, verified badges, game information, and custom sorting. |
| **Profile Display**       | Adds customizable statistics to your profile, including followers, ro-pro likes (RAP), ro-pro rex, verified badges and roblox badges!       |
| **Local Verified Badge**  | Local Verified Badge | Adds a locally rendered verified badge next to selected usernames without modifying their actual account status.     |

See the individual script files for their implementation and configuration options.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the userscript you want to use.
3. Copy the script into a new Tampermonkey userscript.
4. Save the script.
5. Visit the website supported by the userscript.

Some scripts may have additional installation or configuration requirements. Check the comments at the top of each script before installing.
